# 🏥 Hospital Analytics – SQL & Power BI

📌 Project Overview

The "Hospital Analytics Dashboard" is an end-to-end data analytics project developed using "SQL and Microsoft Power BI" to analyze hospital operations, patient characteristics, treatment costs, readmissions, diagnoses, procedures, and clinical metrics.

The project combines "SQL-based data analysis" with **Power BI data cleaning, transformation, DAX calculations and "interactive visualization" to convert raw healthcare data into meaningful business insights.

The dashboard is designed to provide a clear overview of hospital performance and help stakeholders understand patient trends, healthcare costs, readmission patterns, and clinical outcomes.

🎯 Project Objectives

- Analyze hospital admissions and patient activity.
- Understand patient demographics and readmission patterns.
- Analyze treatment and healthcare costs.
- Examine insurance-wise healthcare expenditure.
- Analyze diagnoses and medical procedures.
- Understand the relationship between comorbidities and length of stay.
- Compare government subsidies with out-of-pocket expenses.
- Identify trends that can support data-driven healthcare decision-making.

🛠️ Tools & Technologies

- **SQL** – Data querying, joins, aggregations, filtering and analysis
- **Microsoft Power BI** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and analytical calculations
- **Power BI Service** – Report publishing and dashboard deployment

- Checking data types
- Handling missing or inconsistent values

- Renaming columns where required
- Transforming columns into appropriate formats

 📊 Report Pages

The Power BI report consists of **three interactive analytical pages**.

🏥 1. Hospital Overview Analysis

This page provides a high-level overview of hospital activity, admissions, treatment costs, and financial metrics.

Key KPIs

- **Total Admissions:** 120K
- **Average Stay Length:** 6.85 days
- **Total Treatment Cost:** 11,494M
- **Average Treatment Cost:** 95.78K

Key Visualizations

- Total Admissions by Hospital
- Average Treatment Cost by Tier
- Admissions vs Average Treatment Cost
- Government Subsidy vs Out-of-Pocket Cost

 Interactive Filters

- State
- Ward Type
- Admission Type

This page provides an overall view of hospital utilization and financial performance.

🧑‍⚕️ 2. Patient & Readmission Analysis

This page focuses on patient demographics, insurance costs, discharge outcomes, and readmission patterns.

Key KPIs

- **Total Patients:** 86.40K
- **Average Patient Age:** 48.00
- **Average Previous Admissions:** 0.90
- **30-Day Readmission Rate:** 11.84%

Key Visualizations

- Total Healthcare Cost by Insurance Type
- Readmission Rate by Age
- Patient Distribution by Discharge Type
- Comorbidity Count vs Average Length of Stay

Interactive Filters

- Gender
- State
- Age Group
- Admission Type
- Insurance Type

This page helps analyze patient characteristics and understand patterns associated with readmissions and healthcare expenditure.

🔬 3. Clinical & Treatment Analysis

This page focuses on clinical activity, diagnoses, procedures, comorbidities, and length of stay.

Key KPIs

- **Total Procedures:** 183K
- **Total Diagnoses:** 271.34K
- **Average Comorbidity Count:** 1.43
- **Average Haemoglobin:** 11.84

Key Visualizations

- Total Procedures by Ward Type
- Distribution of Patients by Diagnosis Category

- Comorbidity Count vs Average Length of Stay

Interactive Filters

- Diagnosis Category
- Diagnosis Rank
- Ward Type

This page provides insights into clinical workload and the relationship between patient conditions and hospital stay.
