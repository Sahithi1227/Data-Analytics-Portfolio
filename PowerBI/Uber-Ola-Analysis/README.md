# Uber & Ola Ride Analytics | Power BI

## Project Overview

This project is an interactive Power BI dashboard developed to analyze Uber and Ola ride-booking data and understand different aspects of ride operations and customer behavior.

The dashboard consists of 5 pages with interactive visualizations, KPI cards, filters and charts covering booking patterns, vehicle types, ride distance, cancellations, incomplete rides, payment methods, customer ratings and ride pricing.

## Dataset

The dataset contains ride-booking information including:

- Booking ID
- Vehicle Type
- Vehicle Category
- Booking Status
- Booking Value
- Ride Distance
- Time Period
- Payment Method
- Customer Rating
- Driver Rating
- Pickup Location
- Drop Location
- Cancellation Reasons
- Incomplete Rides
- TAT
- Customer Information

## Key Analysis

- Analyzed bookings across different vehicle types and categories.
- Studied booking patterns across different time periods.
- Analyzed ride distance and distance categories.
- Identified cancellation reasons and driver cancellations.
- Analyzed incomplete rides by vehicle type and time period.
- Studied pickup and drop locations.
- Analyzed payment methods used for bookings.
- Examined customer and driver ratings.
- Analyzed average ride price and TAT differences.
- Compared booking patterns across different vehicle categories.
