Project Overview

This project is an interactive Airline Passenger Satisfaction Analytics dashboard built using Tableau to analyze passenger behavior, travel patterns, flight experience, service ratings, and customer satisfaction.

The dashboard provides a consolidated view of passenger data across different customer types, travel classes, passenger ages, travel types, flight distances, arrival delays, online booking behavior, and service ratings.

Key Analysis

The project analyzes:

- Passenger Distribution by Customer Type & Class to understand the composition of first-time and returning passengers across travel classes.
- Flight Distance by Passenger Age to examine flight-distance patterns across different age groups.
- Passenger Satisfaction by Age to explore satisfaction levels across passenger age groups.
- Online Booking by Travel Class to compare online booking activity across Business, Economy, and Economy Plus classes.
- Arrival Delays by Travel Type to compare arrival-delay patterns between Business and Personal travel.
- Service Ratings by Travel Class to analyze different passenger service ratings across Business, Economy, and Economy Plus classes.

Dashboard Features

- Interactive Class, Customer Type, Age, and Type of Travel filters
- Age range selection for focused analysis
- Multiple visualizations including Bubble Chart, Bar Chart, Area Chart, Line Chart, and Heatmap
- Service-rating comparison across different travel classes
- Interactive dashboard combining passenger behavior, travel patterns, delays, and satisfaction metrics
- Clear visual presentation for exploring passenger experience and airline service performance
