Coffee Shop Sales Analytics | Tableau

Project Overview

This project is an interactive Coffee Shop Sales Analytics dashboard built using Tableau to analyze transaction, revenue, product, store, and time-based sales data.

The dashboard provides a consolidated view of coffee shop performance and allows users to explore sales patterns across different product categories, product types, store locations, transaction dates, weekdays, and transaction hours.

Dataset

The dataset contains 149K+ transactions with information related to:

Product Category
Product Type
Product Detail
Store Location
Transaction Date
Transaction Time
Transaction Quantity
Unit Price
Revenue
Total Cost
Key Analysis

The project analyzes:

- Transactions by Product Type to understand the volume of different products.
- Transaction Quantity by Product Category to compare category-level demand.
- Revenue by Store Location to compare performance across different store branches.
- Hourly Transaction Trends to identify transaction patterns throughout the day.
- Revenue Heatmap by Store, Day & Hour to explore sales activity across locations and time.
- Monthly Revenue Trends to understand changes in revenue over the selected period.
  
Dashboard Features
- Interactive Start Date and End Date parameters
- Store Location and Product Category filters
- Date Range and Month filters
- Multiple visualizations including Treemap, Line Chart, Area Chart, Pie Chart, Bar Chart and Heatmap
- Interactive dashboard combining all major sales insights in one view
