Project Overview

This project is an interactive Indian Banking Transactions Analytics dashboard built using Tableau to analyze banking transaction patterns, account distribution, loan activity, merchant categories, transaction status, and state-wise financial activity.

The dashboard provides a consolidated view of banking data across different account types, transaction types, loan types, merchant categories, transaction statuses, states, and time periods.

Key Analysis

The project analyzes:

- Account Type Distribution to understand transaction/customer distribution across Current, Fixed Deposit, NRI, Salary, and Savings accounts.
- Transactions by Type to compare transaction activity across ATM, Auto Debit, Cheque, Credit Card, IMPS, NEFT, Net Banking, POS, RTGS, and UPI.
- Loan and Merchant Category Distribution to explore the distribution of different loan and merchant categories using a treemap.
- Quarterly Transaction Trends to analyze transaction-status patterns across different quarters and identify changes over time.
- Loan Distribution by State to visualize loan activity geographically across different Indian states.
- Transactions by State in 2019 and 2020 to compare transaction activity across states and observe year-wise patterns.

Dashboard Features:

- Interactive Account Type, Transaction Type, Loan Type, Merchant Category, Transaction Status, State, and Year filters
- State-wise geographical analysis using an interactive map
- Multiple visualizations including Pie Chart, Area Chart, Bar Chart, Line Chart, Treemap, and Map
- Year-wise and quarter-wise transaction analysis
- Comparison of transaction activity across different Indian states
- Interactive dashboard combining banking transactions, loans, account information, merchant categories, and geographical trends
- Clear visual presentation for exploring banking transaction patterns and financial activity
